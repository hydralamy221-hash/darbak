# دربك — Flutter starter (نسخة تطوير)

هذا مشروع بداية متعدد المنصات باستخدام Flutter، يستهدف Android وiOS من قاعدة كود واحدة.

## الموجود حالياً
- واجهة عربية RTL باسم دربك.
- اختيار واجهة الراكب أو صاحب الكية.
- قائمة الخدمات الأساسية المتفق عليها.
- نموذج طلب تجريبي يتحقق من الحقول محلياً.
- توضيح خطوات تسجيل صاحب الكية ومراجعة الإدارة.

## غير جاهز بعد — مهم
هذه ليست نسخة إنتاجية ولا APK/IPA جاهزاً. لا توجد حالياً قاعدة بيانات أو تسجيل دخول حقيقي أو خرائط/GPS فعلي أو دفع أو دردشة أو لوحة إدارة متصلة. لا ترفع وثائق حقيقية إلى هذا النموذج. لا تستخدم أرقام العمولة أو شاشات النموذج كمعاملات مالية حقيقية.

## تشغيل المشروع
1. ثبّت Flutter SDK وAndroid Studio، أو Xcode على جهاز macOS لبناء نسخة iOS.
2. من مجلد المشروع شغّل: `flutter pub get`
3. شغّل: `flutter run`
4. لبناء Android: `flutter build apk --release`
5. لبناء iOS: `flutter build ios --release` (يتطلب macOS وXcode وحساب/إعدادات Apple المناسبة).

## الخطوات اللازمة قبل الإطلاق
1. اختيار مزوّد backend (مثلاً Firebase أو خادم مخصص) وإنشاء بيئات تطوير وإنتاج.
2. تنفيذ المصادقة والصلاحيات وأدوار الراكب/صاحب الكية/الإدارة.
3. تخزين وثائق السائق في مخزن خاص مشفّر مع صلاحيات محدودة وسياسة احتفاظ واضحة.
4. بناء قاعدة بيانات للحجوزات والخطوط والحملات والعمولات وسجل التدقيق.
5. دمج خرائط وموقع وتتبع الرحلة بموافقة المستخدم، ثم إيقاف التتبع عند انتهائها.
6. إنشاء لوحة إدارة آمنة واختبارات، وسياسات الخصوصية والشروط، ومراجعة المتطلبات القانونية بالعراق.
7. اختبار أمني وتجريبي قبل النشر في Google Play وApp Store.
